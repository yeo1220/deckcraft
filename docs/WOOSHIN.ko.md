# 우신 발표

표시 이름: **우신 발표 / Wooshin Slides**. 우신 업무도구의 업무 보고·발표 자료 작성 앱입니다.

- 원본: https://github.com/storytold/deckcraft
- 개인 포크: https://github.com/yeo1220/deckcraft
- 개발 브랜치: `custom/my-app`, 앱 ID: `com.wooshin.tools.slides`.
- 2026-10-15: 제품 표시 문자열, 아이콘, 우신 포털·포크 링크, 운영체제 제품 정보를 변경했습니다.
- `assets/app-icon`은 새로 그린 남색·금색 기능별 벡터 아이콘입니다. `assets/wooshin`은 새 W 마크와 워드마크입니다.
- 원저작권·LICENSE·NOTICE·기여자 정보는 보존합니다. ArtCraft의 제한된 브랜드 이미지와 코드에 있던 마크는 제거했습니다.
- Cargo 패키지와 빌드 입력 이름, 문서 확장자, 엔진 명령은 호환성을 위해 유지합니다. 배포 스크립트는 실행 파일을 `wooshin-slides`(Windows `.exe`)로 복사하고, macOS 번들은 `WooshinSlides.app`으로 만듭니다.
- Windows/macOS 설치본과 서명은 별도 빌드·검증 대상입니다. 이 변경만으로 배포 완료를 의미하지 않습니다.
